# ⚡ Bionic Web Reader

> A lightweight, privacy-focused Chromium browser extension that transforms any webpage, article, or blog into Bionic Reading format to boost reading speed and visual focus.

---

## ✨ Features

* **Instant Bionic Transformation:** Highlights the initial letters of words to create eye fixation anchors.
* **Customizable Fixation Strength:** Adjust bolding intensity from **30% to 75%** in real-time.
* **Non-Destructive DOM Parsing:** Preserves page layout, code blocks, images, links, and styling.
* **Instant Revert:** Toggle back to the original text without reloading the page.
* **Keyboard Shortcut:** Quickly toggle reading mode using `Alt + B` (Windows/Linux) or `Option + B` (macOS).
* **100% Client-Side & Private:** Zero tracking, zero telemetry, and no external API requests.
